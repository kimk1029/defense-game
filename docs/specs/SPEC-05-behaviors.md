# SPEC-05 포탑 행동 · 릴레이 오라

**관련:** GDD §4 · 구현 `tower.gd`, `*_behavior.gd` · 테스트 `tests/test_behaviors.gd`

## 수용 기준
- **AC-05-1** 기본 타깃은 사거리 안에서 경로 진행도(progress)가 가장 큰 적이다.
- **AC-05-2** 릴레이 오라
  - 다른 포탑이 릴레이의 사거리 안에 있으면 공속 보너스 `0.12 + 0.04 × 릴레이 level`을 받는다.
  - 여러 릴레이의 보너스는 합산하고 상한은 0.6이다. 릴레이 자신은 보너스를 받지 않는다.
- **AC-05-3** 번개 연쇄
  - 연쇄 횟수: Lv1 2회, Lv2~4 3회, Lv5 4회
  - 피해는 튈 때마다 ×0.7, 연쇄 거리는 150이다.
  - **이미 죽은 적(`dead`)과 이미 맞은 적은 연쇄 대상에서 제외한다.**
- **AC-05-4** 박격포는 60px 미만의 적을 타깃으로 삼지 않는다.
- **AC-05-5** 드론 수: Lv1~2는 2기, Lv3~4는 3기, Lv5는 4기
- **AC-05-6** 냉기 둔화량: Lv1 0.20, Lv2~4 0.25, Lv5 0.35. 규칙은 strongest다.
