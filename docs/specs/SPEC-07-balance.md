# SPEC-07 밸런스

**관련:** GDD §6, §7 · 구현 `scripts/balance_config.gd`, `wave_spawner.gd`, `main.gd`, `game_state.gd` · 검증 `tools/balance_sim.gd`, `tests/test_balance.gd`

## 측정 방법
- `tools/balance_sim.gd`의 봇은 "평균적인 플레이어"를 흉내 낸다.
  - 경로를 가장 많이 덮는 자리부터 짓는다.
  - 혼합 빌드 순서를 따르고, 포탑이 4기 이상이면 강화를 섞는다.
- `--fixed-fps 60`으로 결정적으로 실행하고, seed 1·2·3의 결과를 비교한다.

## 기준선 (660b35d, 조정 전)
| 스테이지 | 도달 웨이브 (seed 1/2/3) | 생명 손실 |
|---|---|---|
| 1 초원의 길 ★ | 4 / 3 / 3 (패배) | 1웨이브부터 누수 |
| 2 지그재그 ★★ | 30+ / 30+ / 30+ | 0 |
| 3 나선 계곡 ★★★ | 30+ / 30+ / 30+ | 0 |
| 4 격자 미로 ★★ | 8 / 5 / 5 (패배) | 1웨이브부터 누수 |

진단
1. 시작 골드 150으로는 포탑 1기뿐이다. 1웨이브 러너 HP 29가 발리스타 Lv1 피해 26보다 높다.
2. 적 HP는 선형으로 증가하지만, 포탑 화력은 수와 강화로 복리처럼 증가한다.
3. 경로 길이에 따른 스테이지 편차를 보정하는 장치가 없다.

## 목표 (봇 기준 수용 기준)
- **AC-07-1 초반 공정성:** 모든 스테이지에서 1~3웨이브의 생명 손실 합이 2 이하다. `tests/test_balance.gd`로 자동 검증한다.
- **AC-07-2 압박:** 모든 스테이지에서 25웨이브 이전에 생명 손실이 처음 발생한다. 무손실로 끝까지 가면 실패다.
- **AC-07-3 난이도 순서:** 도달 웨이브(3 seed 평균)가 표시 난이도와 같은 순서다.
  - ★(1) ≥ ★★(2, 4) ≥ ★★★(3)
  - 1스테이지는 20웨이브 이상 도달한다.
- **AC-07-4 끝이 있음:** 모든 스테이지에서 봇은 40웨이브 이전에 패배한다.
- **AC-07-5 준비 시간:** 첫 웨이브 전 15초, 웨이브 사이 5초다.
  - 근거: 브라우저 E2E에서 자동 스크립트조차 3.5초가 걸려, 3초 대기에서는 설치가 웨이브 시작과 겹쳤다.
- **AC-07-6 단일 원천:** 시작 골드, 대기 시간, HP 곡선, 스테이지 배율, 클리어 보너스는 `BalanceConfig` 한 곳에서 정의한다.

## 결과 (조정 후)
조정값 (`scripts/balance_config.gd`)
- 시작 골드: 150 → **250**
- 클리어 보너스: 없음 → **`10 + 2w`**
- HP 곡선: 없음 → **`1 + 0.0025(w-1)²`**
- 스테이지 배율: **1 0.9 / 2 1.6 / 3 1.85 / 4 1.05** (1~7웨이브에 걸쳐 1.0에서 서서히 오름)
- 준비 시간: 첫 웨이브 3초 → **15초**

| 스테이지 | 도달 웨이브 (seed 1/2/3) | 평균 | 1~3웨이브 손실 | 첫 누수 |
|---|---|---|---|---|
| 1 초원의 길 ★ | 23 / 22 / 22 | 22.3 | 0 | 4~21 |
| 2 지그재그 ★★ | 22 / 19 / 21 | 20.7 | 0 | 7~21 |
| 4 격자 미로 ★★ | 22 / 19 / 21 | 20.7 | 0 | 7~14 |
| 3 나선 계곡 ★★★ | 16 / 19 / 17 | 17.3 | 0 | 7~14 |

판정
- AC-07-1 ✅ 초반 손실은 전 스테이지 0이고, `tests/test_balance.gd`로 자동 검증한다.
- AC-07-2 ✅ 첫 누수는 4~21웨이브다.
- AC-07-3 ✅ 순서는 22.3 ≥ 20.7 ≥ 17.3이고, 1스테이지는 20 이상이다.
- AC-07-4 ✅ 모두 40웨이브 이전에 패배한다.
- AC-07-5 ✅ 준비 시간은 15초/5초다.
- AC-07-6 ✅ 수치는 `BalanceConfig` 한 곳에 있다.

한계: 봇 1종 기준이다. 실제 사람의 플레이 테스트로 체감 난이도를 확인해야 한다. 특히 3스테이지는 배율에 민감하다(1.85 → 1.95에서 평균이 2웨이브 떨어짐).
