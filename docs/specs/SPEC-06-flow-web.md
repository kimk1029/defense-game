# SPEC-06 게임 흐름 · 웹 · E2E

**관련:** GDD §1, §7 · 구현 `main.gd`, `game_state.gd`, `title.gd` · 테스트 `tests/test_smoke.gd`, `tools/e2e_web.js`

## 수용 기준
- **AC-06-1** `GameState.reset_run()`은 골드 150, 생명 20, 웨이브 0으로 초기화한다.
  - `spend_gold`는 골드가 부족하면 false이고 상태를 바꾸지 않는다.
- **AC-06-2** 스모크: 스테이지 1~4 각각 main 씬을 띄운다.
  - 포탑을 배치한 채 진행했을 때 스크립트 에러 없이 웨이브가 1 이상 진행된다.
- **AC-06-3** 처치하면 골드가 늘고, 누수가 생기면 생명이 줄어든다. 생명이 0 이하가 되면 게임 오버다.
  - 게임 오버 후에는 시뮬레이션(스포너, 적, 포탑)이 멈춘다.
- **AC-06-4** 웹 빌드
  - 한글 UI가 정상 렌더링된다. 웹에는 시스템 폰트 대체가 없으므로 한글 폰트를 번들한다.
  - 디버그 빌드는 `window.rbState`를 노출한다.
- **AC-06-5** 브라우저 E2E(`tools/e2e_web.js`): 실제 캔버스 클릭만으로 다음 과정이 동작한다.
  - 타이틀 → 시작 → 포탑 설치 → 인스펙터 열기 → 강화 → 판매
